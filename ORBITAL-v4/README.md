# ORBITAL — Space Mission Design Game (v4)

NASA Space Apps Challenge 2026 · *Space Mission Design Game*

Одиночная игра: собери спутник, успей к окну запуска, проведи 5 дней миссии. Жёстких запретов нет — у каждого решения есть цена в очках.

## Запуск
Двойной щелчок по `index.html`. Сервер не нужен.

## Что есть
- **Новая игра / Продолжить** — агентство с названием, общий счёт и журнал полётов (хранятся в браузере).
- **Ангар из 5 шагов** — орбита, приборы (сколько угодно), энергия, связь, ракета. Инженер словами объясняет последствия; ничего не блокируется.
- **Сборка по дням** с событиями и окнами запуска.
- **Запуск** — видео старта (`assets/videos/launch.mp4`). Шанс успеха = надёжность ракеты, перевес его снижает.
- **Полёт** — карта Земли с ночной стороной, трассой, станциями и целями; подсказка «что делать сейчас»; 6 уроков.
- **Итоги** — таблица счёта, советы, реальная миссия NASA.

## Счёт
| | |
|---|---|
| Наука | очки за каждый снимок, доставленный на Землю вовремя (с комбо) |
| Эффективность | +20 за каждый сэкономленный $1M (если доставлен хотя бы один снимок) |
| Старт до начала сезона | +300 |
| Перерасход | −60 за каждый $1M сверх бюджета |
| Перевес | −15 за каждый лишний кг; шанс успешного старта падает |
| Опоздание к сезону | −3% науки за день (до −60%) |
| Неудачный полёт | −1000 (ракета потеряна или спутник уничтожен) |

## Реальная физика (sim.js)
Период по Кеплеру, прецессия J2 (SSO), вращение Земли, положение Солнца по дате, тень Земли, зоны видимости реальных станций NASA, реальные регионы целей.
